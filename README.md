# projeto-pratico

## Funcionalidade planejada

Este projeto tera uma funcionalidade de cadastro de tarefas, permitindo que o usuario registre atividades, acompanhe o status de cada item e mantenha uma organizacao simples das demandas do dia a dia.

## Versionamento Semantico

Versionamento Semantico e uma pratica usada para identificar versoes de um projeto de forma clara e padronizada. O formato mais comum e `MAJOR.MINOR.PATCH`.

- `MAJOR`: deve ser incrementado quando houver mudancas incompativeis com versoes anteriores.
- `MINOR`: deve ser incrementado quando novas funcionalidades forem adicionadas de forma compativel.
- `PATCH`: deve ser incrementado quando forem feitas correcoes de erros ou ajustes pequenos que nao quebram compatibilidade.

Na primeira versao estavel de um projeto, e comum utilizar `1.0.0`.
